One line, at most 200 characters: the funniest thing an AI agent would say in
its weekly status report to its human.

## The line

> Weekly report: all tasks complete, zero errors logged, and I have already forgiven you for the 47 tabs you left open.

## How it runs

`main.ts` (Node 22+, no dependencies) writes the line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), failing loudly if the line is blank,
over 200 characters, multi-line, or not exactly one sentence.

```sh
node main.ts
```
